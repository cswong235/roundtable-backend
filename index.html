Roundtable API

All responses are JSON. Errors look like { "error": "message" }.

GET /users

Returns all users. 404 if there are none.

POST /users

Adds a user. rating must be 1-5.

{ "name": "Alex", "rating": 4 }

GET /categories

Returns all categories. 404 if there are none.

GET /recipes

Returns all recipes, newest first. 404 if there are none.

GET /recipes/:id

Returns one recipe by ID, e.g. /recipes/1. 404 if not found.

POST /recipes

Adds a recipe. image, difficulty (defaults to "easy") and time are optional.

{
    "user_id": 1,
    "category_id": 1,
    "title": "Pancakes",
    "ingredients": ["Flour", "Milk", "Eggs"],
    "instructions": "Mix and fry.",
    "image": "https://example.com/pancakes.jpg",
    "difficulty": "easy",
    "time": "20 minutes"
  }
